# 00-entry

## 目的
この文書は、全員が作業着手の最初に読み、今回の変更が通常変更か高リスク変更か、自分の役割は何か、次にどの文書を読むかを決めるための入口です。

## この文書で決めること
- 今回の変更が通常変更か高リスク変更か
- 自分の役割が何か
- 次に読むべき L1 / L2 はどれか

## 役割の選び方
- 実装や設計、テストを行う人は **開発者**
- 差分を見て指摘や差し戻し判断をする人は **レビュー担当**
- 承認可否やマージ可否を最終判断する人は **PR 承認者**
- すべての役割に共通して、この文書は最初に読む

## 高リスク変更の定義
以下のいずれかに該当する場合は高リスク変更とする。

- 認証
- 認可
- 権限変更
- セッション管理
- DB スキーマ変更
- 外部 API / 外部通信追加・変更
- 個人情報
- 秘密情報
- ログ出力方針変更
- 依存関係追加・更新
- 本番設定変更
- セキュリティ設定変更

## 判定手順
1. 今回の変更内容を短く 1 文で言う
2. 高リスク変更の定義と照合する
3. 1 つでも当てはまれば高リスク変更とする
4. 迷ったら高リスク変更として扱う
5. 自分の役割に応じた L1 を読む
6. 高リスク変更なら該当する L2 を追加で読む

- AI の提案を根拠なく正しい前提で進めない
