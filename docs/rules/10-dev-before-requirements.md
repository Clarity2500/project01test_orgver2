# 10-dev-before-requirements

## 目的
要件確認の前に、何をやるか・何をやらないかを固定し、スコープ逸脱と見落としを防ぐ。

## この工程での禁止事項
- 完了条件が曖昧なまま進めない
- 対象外の変更を勝手に含めない
- 触ってよい範囲が不明なまま設計・実装に入らない

## この工程での確認項目
- 対象機能のスコープ
- 完了条件
- 対象外
- 触ってよいファイル / 領域
- 触ってはいけないファイル / 領域
- 高リスク変更に該当するか

## 高リスク変更時の追加読解先
- 高リスク変更なら該当する `40-46` 系を読む

- 設計に進む前: `11-dev-before-design.md`
- すぐ実装に進む軽微変更: `12-dev-before-implement.md`
