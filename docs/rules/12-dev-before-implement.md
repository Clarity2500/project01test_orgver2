# 12-dev-before-implement

## 目的
実装の前に、禁止実装と再利用方針を確認し、安全で一貫した実装に寄せる。

## この工程での禁止事項
- 設計を無断で逸脱しない
- 既存で実現できるのに新規依存を増やさない
- 秘密情報をコード・設定・ログへ出さない
- セキュリティに関わる値をハードコードしない

## この工程での確認項目
- 設計との差分がないか
- 再利用できる既存実装はあるか
- 追加依存は必要最小か
- 禁止実装に触れていないか
- ログ出力禁止事項に触れていないか
- 実装後のセルフレビュー観点

## 高リスク変更時の追加読解先
- 依存追加: `45-risk-dependency.md`
- 秘密情報 / 個人情報 / ログ: `44-risk-secrets-pii.md`
- 本番設定: `46-risk-production-config.md`
