# 14-dev-before-review-request

## 目的
レビュー依頼の前に、レビュー担当が迷わず判断できる情報を揃える。

## この工程での禁止事項
- リスク分類を付けずにレビュー依頼しない
- 危険箇所を隠したまま依頼しない
- 見てほしい論点を整理せずに依頼しない

## この工程での確認項目
- 通常変更 / 高リスク変更の分類
- 危険箇所の明示
- レビュー担当に見てほしい観点
- 未確定事項の有無
- 人間承認が必要な箇所

## 高リスク変更時の追加読解先
- 高リスク変更なら該当する `40-46` 系を併記する

## 次の工程で読む文書
- PR 前: `15-dev-before-pr.md`
- レビュー担当は `20-reviewer-before-review.md` を読む
