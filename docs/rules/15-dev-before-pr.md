# 15-dev-before-pr

## 目的
PR 作成の前に、承認とレビューに必要な情報が不足しないよう整える。

## この工程での禁止事項
- 差分説明がないまま PR を作らない
- 対象外や制約を書かずに PR を出さない
- 高リスク変更を通常変更として記載しない

## この工程での確認項目
- 差分説明
- 対象範囲
- 対象外
- リスク分類
- 必要承認
- 前提条件
- 既知の制約
- ロールバック観点の有無

## 高リスク変更時の追加読解先
- 高リスク変更なら該当する `40-46` 系の確認結果を明示する

## 次の工程で読む文書
- 承認者は `30-approver-before-approve.md` を読む
