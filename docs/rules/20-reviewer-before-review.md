# 20-reviewer-before-review

## 目的
レビューの前に、何を見て差し戻すかを固定し、レビューの属人化を防ぐ。

## この工程での禁止事項
- 好みだけで差し戻さない
- 重要なリスクを見落としたまま承認しない
- 要件・設計・テスト観点を飛ばしてコードだけ見ない

## この工程での確認項目
- 要件逸脱
- 設計逸脱
- セキュリティ逸脱
- テスト不足
- 差分拡大の有無
- 高リスク変更の見落とし有無

## 高リスク変更時の追加読解先
- 高リスク変更なら該当する `40-46` 系を読む
