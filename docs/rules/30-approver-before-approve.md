# 30-approver-before-approve

## 目的
承認の前に、承認条件が揃っているかを固定観点で確認する。

## この工程での禁止事項
- 必要レビューが揃っていないのに承認しない
- 高リスク変更で追加確認が未了のまま承認しない
- 差分範囲が曖昧な PR を承認しない

## この工程での確認項目
- 必要レビュー数
- 必要役割の確認有無
- 高リスク変更の追加確認有無
- CI / テスト結果
- 差分範囲
- 承認条件の明記

## 高リスク変更時の追加読解先
- 高リスク変更なら該当する `40-46` 系を読む
