# 41-risk-authorization

## 定義
認可、ロール、権限境界、アクセス制御、操作可否条件の変更を含む変更。

## 事故が起こりやすいポイント
- 権限漏れ
- UI 制御だけで許可判定してしまう
- 所有者確認やロール判定の抜け

## 設計時の確認項目
- 権限境界が明確か
- 誰が何をできるか説明できるか
- 例外ロールの扱いは定義済みか

## 実装時の確認項目
- サーバー側で必ず認可しているか
- 所有者確認があるか
- 隠しフラグで権限を代用していないか

## テスト時の確認項目
- 権限あり / なしの両方
- 境界ロール
- 他人データへのアクセス拒否

## レビュー時の確認項目
- UI だけで制御していないか
- 例外的操作が無制限になっていないか

## 承認時の確認項目
- 追加権限の影響範囲が確認されているか
- 高権限操作に十分なレビューがあるか
