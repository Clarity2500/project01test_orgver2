# 42-risk-db-schema

## 定義
DB スキーマ、マイグレーション、制約、インデックス、データ移行を含む変更。

## 事故が起こりやすいポイント
- 既存データ破損
- 互換性喪失
- ロールバック不能
- 制約不足や過剰制約

## 設計時の確認項目
- 変更対象テーブルと影響範囲
- 後方互換性
- ロールバック方針
- データ移行要否

## 実装時の確認項目
- マイグレーション順序は安全か
- 既存データ前提を壊さないか
- 本番適用時の失敗影響は把握済みか

## テスト時の確認項目
- 既存データありのケース
- 移行失敗時
- 旧コード / 新コード混在時

## レビュー時の確認項目
- 破壊的変更が隠れていないか
- データ移行の前提が説明されているか

## 承認時の確認項目
- ロールバック観点があるか
- 本番適用リスクが明示されているか
