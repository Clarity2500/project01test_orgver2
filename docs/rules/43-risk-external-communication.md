# 43-risk-external-communication

## 定義
外部 API、Webhook、外部サービス送信、第三者通信先の追加・変更を含む変更。

## 事故が起こりやすいポイント
- 想定外の送信先
- 機微情報送信
- タイムアウトや失敗時の挙動不備
- リトライ暴走

## 設計時の確認項目
- 通信先と送信データ
- 認証方式
- タイムアウト / リトライ方針
- 障害時の代替挙動

## 実装時の確認項目
- 許可された通信先だけか
- 機微情報を送っていないか
- 例外処理が安全か

## テスト時の確認項目
- 正常応答
- 失敗応答
- タイムアウト
- リトライ時の挙動

## レビュー時の確認項目
- 外部依存失敗時に危険側へ倒れないか
- 不要な送信データがないか

## 承認時の確認項目
- 通信先・データ種別・障害時挙動が明示されているか
