# 91-glossary

## 用語集

### 通常変更
高リスク変更の定義に当てはまらない変更。

### 高リスク変更
認証、認可、権限、DB、外部通信、個人情報、秘密情報、依存追加、本番設定など、事故や影響が大きい変更。

### 開発者
要件確認、設計、実装、テスト、レビュー依頼、PR 作成を行う人。

### レビュー担当
差分を見て、要件逸脱、設計逸脱、セキュリティ逸脱、テスト不足などを確認する人。

### PR 承認者
必要なレビュー・確認が揃っているかを見て、承認可否・マージ可否を判断する人。

### 信頼境界
どこからどこまでを自分たちが信頼してよいかの境目。

### ロールバック
変更を戻すための方法や前提。

### 入口
作業着手時に最初に読む `00-entry.md` のこと。
